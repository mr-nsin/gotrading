# Product Roadmap

## Phase 1: MVP (Months 1-2)
*   Fyers API Integration.
*   Manual Voice Execution for simple multi-leg spreads (Straddles, Condors).
*   Real-time P&L Grid (WebSocket).

## Phase 2: Algorithmic Beta (Months 3-4)
*   Launch 2 automated strategies: 0DTE Gamma Blast & Volatility Skew Arbitrage.
*   Target 100 concurrent Beta Users.
*   Comprehensive SEBI Audit Logging implementation.

## Phase 3: Advanced AI & Analytics (Months 5-6)
*   Pairs Trading (Statistical Arbitrage) module.
*   Deep Reinforcement Learning (DRL) dynamic delta hedging.
*   B2B White-label API launch.

## Phase 4: Multi-Broker & Asset Expansion (Months 7-8)
*   Add Zerodha (Kite Connect) and Upstox integrations.
*   Expand from Nifty/BankNifty to MCX Commodities (Crude Oil, Gold).

## Phase 5: Enterprise HFT Features (Months 9-12)
*   Direct Market Access (DMA) via FIX protocol bypassing retail APIs.
*   Co-location server hosting setup at NSE.
